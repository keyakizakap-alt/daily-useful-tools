# アイデア発想の記録 — 2026-08-22

## 1. 発想プロセス

100体のエージェントによるブレインストーミングを行った。
各エージェントには「領域 × 切り口」の固有のレンズを1つずつ割り当て、
他のエージェントと視点が重複しないようにした。

- **領域（10種）**: 家事・掃除・料理 / 仕事・オフィス業務・会議 / 学習・資格試験・語学 /
  健康・睡眠・運動・メンタル / お金・家計・節約・税金 / 育児・介護・家族 /
  文章作成・情報整理・メモ / 買い物・食材・在庫管理 / 趣味・創作・エンタメ / 移動・旅行・地域生活
- **切り口（10種）**: 「毎日5分の面倒」を消す / 意思決定の迷いを減らす / 記録が続かない障壁を壊す /
  複数の情報源を束ねる / 見えないコストを可視化する / 一人だと続かないことを仕組みで支える /
  既存アプリが重すぎる領域を極小ツールで置き換える / 日本特有の商習慣・制度・日本語事情に最適化する /
  逆転の発想 / データを一切外部送信しないローカル完結

10 × 10 = 100 のレンズを各エージェントに割り当て、それぞれ2案ずつ発想させた。

### 実行結果と制約

ブレインストーミングの途中でAPIのセッション上限に達したため、
**100体中49体が完走し、98件のアイデアを収集した時点で打ち切りとなった**。
完走したのは領域1〜5（家事・仕事・学習・健康・お金）にあたるレンズ #0〜#48 で、
領域6〜10（育児・文章作成・買い物・趣味・移動）は未実施のまま残っている。

このため、以下の選考は「98件の母集団に対する選考」であり、
本来意図した100体・200案の全量に対するものではない。
未実施領域は翌日以降の発想対象として持ち越す。

## 2. 選考プロセス

収集した98件を、以下の3軸で評価した。

| 軸 | 評価内容 |
| --- | --- |
| 実用性 | 日本のユーザーが本当に毎日開くか。3日で飽きないか。既存の代替手段より明確に楽か |
| 新規性 | 既存アプリや手作業と比べて発想が新しいか。「その手があったか」と思うか |
| 実装可能性 | 外部API・ログイン・サーバなしで1日でMVPが作れるか。中核ロジックに自動テストが書ける密度があるか |

## 3. 採用したアイデア: 段取りキッチン

**「できあがり時刻から逆算して、複数の料理の調理段取りを1本のタイムラインに組み立てる」**

### 選定理由

**独立した4つのレンズが同じ課題に収束した**ことが決め手になった。
以下はいずれも別々のエージェントが、別々の切り口から到達した案である。

| # | アイデア名 | 切り口 |
| --- | --- | --- |
| 06 | 家族の食卓オーケストレーター | 複数の情報源を束ねる |
| 09 | 調理工程時短最適化エンジン | 見えないコスト・ムダを可視化する |
| 14 | 調理パラレル指示 | 一人だと続かないことを仕組みで支える |
| 17 | 逆算クック | 逆転の発想 |

異なる切り口から同一の課題に到達したことは、その課題が実在し、
かつ既存ツールで解けていないことの強い示唆と判断した。

3軸での評価は次のとおり。

- **実用性**: 夕食は毎日発生する。「何品も作ると、できあがりの時間がバラバラで、
  最初に作ったものが冷める」という失敗は家庭料理で日常的に起きている。
- **新規性**: レシピアプリは「何を作るか」と「1品の作り方」は教えてくれるが、
  **複数の料理を1人の調理者がどう並行させるか**は教えてくれない。
  ここが未充足であり、既存のレシピ検索とは競合しない。
- **実装可能性**: 中核が「有限リソース下の後ろ向きスケジューリング」という
  明確な計算問題であり、純関数として切り出して自動テストが書ける。
  UIを剥がしてもロジックだけで検証できる密度がある。

### 落選した主な候補と理由

| アイデア | 落選理由 |
| --- | --- |
| スマート復習ランカー / 危機度トラッカー（忘却曲線ベースの復習管理） | ロジックは testable だが Anki 等の完成品が普及済みで新規性が低い |
| あたらぬ不安スコア（朝の不安が現実になったか記録し予測精度を可視化） | 発想は極めて新しいが、毎日開く動機が弱く、ロジックが薄い |
| 時間制約掃除プランナー（時間予算内で最大効果の掃除タスクを選ぶ） | ナップサック問題として良質だが、掃除は毎日発生しない |
| 会議原価ナビ（会議コストのリアルタイム表示） | 計算が単純（人数×時給×時間）でテストする密度がない |
| 瞬時記録 家計簿 | 入力補完の辞書づくりが本体で、1日のMVPに収まらない |
