# 段取りキッチン

**できあがり時刻から逆算して、複数の料理の調理段取りを1本のタイムラインに組み立てるツール。**

レシピアプリは「何を作るか」と「1品の作り方」は教えてくれますが、
**1人の調理者が複数の料理をどう並行させるか**は教えてくれません。段取りキッチンはそこだけを解きます。

```
18:30 に食べたい。ごはん・味噌汁・生姜焼きを作る。1人で。
        ↓
16:55  ごはん      米をとぐ           5分
17:00  ごはん      浸水させる         30分（放置）
17:30  ごはん      炊飯する           40分（放置）
18:01  生姜焼き    たれを合わせる     3分   ⏳ 裏でごはんが炊飯中
18:04  味噌汁      具材を切る         5分   ⏳ 裏でごはんが炊飯中
   …
18:28  味噌汁      味噌を溶く         2分
18:30  ── できあがり ──
```

## 特徴

- **できあがり時刻から逆算** — 「何時に始めればいいか」が確定します
- **つきっきり / 放置 の区別** — 煮込みの裏に別の料理の作業を差し込み、全体を短くします
- **冷めてよい料理は先に** — 料理ごとに「できあがりの◯分前でOK」を指定できます
- **人数を変えて試せる** — 2人で作ったらどれだけ短くなるかが事前に分かります
- **通信は一切なし** — ログイン不要・オフラインで動作し、データは端末内の localStorage だけに保存されます

## 使い方

ES モジュールを使うため、`file://` で直接開かず HTTP で配信してください。

```bash
cd src
python3 -m http.server 8080
# ブラウザで http://localhost:8080/web/index.html を開く
```

Node.js があれば次でも構いません。

```bash
npx http-server src -p 8080
```

### 画面の操作

1. **できあがり時刻** と **作る人の数** を設定します
2. 「よく作る料理から追加」で献立を組みます（自分で工程を入力することもできます）
3. 各工程を **つきっきり**（切る・炒める＝手が塞がる）か **放置**（煮る・炊く＝離れられる）に設定します
4. 冷めてよい料理は「できあがりの◯分前でOK」に分数を入れます（サラダなら45など）
5. 下部のタイムラインの順に作ります

入力内容は自動保存され、次回開いたときに復元されます。

## 中核アルゴリズム

「できあがり時刻の何分前か（offset）」という座標系で、後ろ向きにスケジューリングします。

1. 各料理の工程を、最後の工程から前に積み上げて理想の offset を求める
2. つきっきり工程を、**時間的に遅いものから順に**確定させる
3. 調理者の人数を超えて重なる場合、その工程と**同じ料理の手前の全工程**をまとめて前倒しする
4. 全工程の開始 offset の最大値が総所要時間。できあがり時刻から引くと調理開始時刻になる

詳細と正当性の議論は [docs/design.md](docs/design.md) を参照してください。

### 保証していること

最適解であることは保証しませんが、**破綻しないこと**をテストで保証しています。
ランダム生成した300件の献立に対し、次が常に成り立つことを検証しています。

- つきっきり工程が調理者の人数を超えて重ならない
- 各料理の工程が調理順を守る
- どの料理もできあがり時刻までに完成する
- 調理者を増やすと総所要時間は決して長くならない
