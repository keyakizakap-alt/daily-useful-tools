# 要件定義書 - わりかんスッキリ

## 1. 背景・課題

飲み会や旅行などグループで出費を立て替えたとき、「誰が誰にいくら払えば清算が終わるか」を
手計算するのは面倒で間違いやすい。既存の割り勘アプリの多くはアカウント登録や通信を必要とし、
ちょっとした集まりで気軽に使うには重い。

## 2. 目的

- ブラウザだけで完結する（サーバー通信・アカウント登録不要）割り勘計算ツールを提供する。
- 支払いの立て替え履歴から、各人の収支（プラス・マイナス）と、
  精算に必要な最小限の送金リストを自動計算する。
- 日本語UIで、専門知識がなくても直感的に使えるようにする。

## 3. 想定ユーザー・ユースケース

- 友人同士の旅行やイベントの経費精算をしたい人
- 飲み会の幹事で、複数回の立て替えをまとめて清算したい人
- 特定の出費だけ一部のメンバーで割り勘したい場合（例: タクシー代は3人だけ）

## 4. 機能要件

1. メンバー登録: 参加者の名前を追加・削除できる。
2. 支出登録: 各支出について「支払った人」「金額」「対象者（誰の分の支出か）」を登録できる。
   対象者を指定しない場合は全員で均等割りする。
3. 収支計算: 各メンバーについて「払いすぎている額（＋）」「不足している額（－）」を算出する。
4. 精算リスト生成: 送金回数が最小になるように「誰から誰へいくら」の一覧を生成する
   （貪欲法：最大の貸し手と最大の借り手を都度マッチングする）。
5. 端数処理: 金額は円単位の整数として扱い、割り切れない場合は差額が1円単位で
   出ないよう調整する（合計の整合性を保証する）。
6. 全て日本語UIで表示する。

## 5. 非機能要件

- 外部通信・サーバー・データベースを必要としない静的Webページとして動作する。
- ロジック部分（計算エンジン）はUIから独立させ、自動テストで検証可能にする。
- 追加の npm 依存パッケージを使用しない（Node.js 標準機能のみでテスト可能）。

## 6. スコープ外（今回のMVPでは対応しない）

- データの永続化（ローカルストレージへの保存など）
- 複数通貨対応
- ユーザー認証・共有機能
