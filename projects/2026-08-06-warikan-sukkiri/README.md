# わりかんスッキリ（Warikan Sukkiri）

グループでの立て替え払いを、誰が誰にいくら払えば清算が終わるか自動計算する
日本語UIのシンプルな割り勘計算ツールです。サーバー通信・アカウント登録は不要で、
ブラウザだけで完結します。

## 使い方

### 方法1: 単一ファイル版を開く（最も簡単・サーバー不要）

CSS/JSを全てインライン化した1ファイル版をビルドすると、
そのHTMLをブラウザで開くだけで動作します。

```bash
node build.js
# -> dist/warikan-standalone.html が生成される
# このファイルをブラウザで開く（ダブルクリックでも可）
```

### 方法2: ローカルサーバーで開発版を起動

```bash
cd src
npx http-server . -p 8080 -s
# ブラウザで http://localhost:8080/index.html を開く
```

> `src/index.html` を `file://` で直接開くと、`<script type="module">` に対する
> ブラウザのCORS制限により読み込みに失敗します。開発版はローカルサーバー経由で
> 起動してください。サーバーを立てずに使いたい場合は方法1を利用します。

## 機能

1. メンバー登録
2. 支出登録（支払った人・金額・対象者を指定。対象者未指定なら全員で均等割り）
3. 精算結果の計算（各メンバーの収支＋最小限の送金リスト）

## ディレクトリ構成

```
docs/       設計・要件ドキュメント
src/        実装（計算エンジン + UI）
tests/      計算エンジンの自動テスト
feedback/   セルフレビュー・改善記録
build.js    単一HTMLファイル版のビルドスクリプト
dist/       ビルド生成物（単一ファイル版）
```

## テストの実行

追加の依存パッケージは不要です（Node.js標準の `node:test` を使用）。

```bash
node --test
```
