# わりかんスッキリ（Warikan Sukkiri）

グループでの立て替え払いを、誰が誰にいくら払えば清算が終わるか自動計算する
日本語UIのシンプルな割り勘計算ツールです。サーバー通信・アカウント登録は不要で、
ブラウザだけで完結します。

## 使い方

```bash
cd src
npx http-server . -p 8080 -s
# ブラウザで http://localhost:8080/index.html を開く
```

または `src/index.html` をブラウザで直接開いても動作します（`type="module"` を
使用しているため、`file://` で開く場合はブラウザによって制限される可能性が
あります。ローカルサーバー経由での起動を推奨します）。

## 機能

1. メンバー登録
2. 支出登録（支払った人・金額・対象者を指定。対象者未指定なら全員で均等割り）
3. 精算結果の計算（各メンバーの収支＋最小限の送金リスト）

## ディレクトリ構成

```
docs/       設計・要件ドキュメント
src/        実装（計算エンジン + UI）
tests/      計算エンジンの自動テスト
feedback/   セルフレビュー・改善記録
```

## テストの実行

追加の依存パッケージは不要です（Node.js標準の `node:test` を使用）。

```bash
node --test
```
