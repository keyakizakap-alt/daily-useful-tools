  - [x] 大人2人・7日で 水42L・主食42食・ボンベ12本・トイレ70回分

  - [x] 期限切れの在庫を充足量に数えない
  - [x] 不正な JSON で画面が止まらず、日本語のエラーが出る

## 1. 良かった点

- U1「人数を入れた瞬間に『水 42L』と出る。買う物がはっきりした」

## 3. 根本原因への集約

- **再描画で状態が失われる（R1, R10, R11）**: 描画を「毎回作り直す」方式のまま、フォーカス・日付・一時表示を描画の中で扱うようにした。
- **入力ミスでデータが消える（R3, R4, R5）**: 削除・置き換えは明示的な操作（ボタン・確認）でだけ起きるようにした。壊れたデータも消さずに退避する。
- **検証の抜け（R2, R12a）**: 外部入力を引く表は `Object.create(null)`、文字の除去はエスケープで書き、どちらもテストで固定した。
- **意図的に変えないもの**: R6 の重み付け（根拠のある重みを示せないため、備品を外すだけにした）、R12b（配信側ヘッダで対応済み）、R14（スコープ外）。
