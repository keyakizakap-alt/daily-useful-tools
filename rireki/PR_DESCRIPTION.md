# としめくり — 履歴書の学歴年表・年号早見（`rireki/`）

## アイデアの概要と解決する課題

履歴書の学歴欄を書くたびに「中学を何年に卒業したか」「平成31年か令和元年か」「早生まれは1年ずれるのか」をネットの早見表で調べ直している、という日本特有の困りごとを解決する。

生年月日と最終学歴を入れるだけで、学歴欄（入学・卒業の年月）を和暦・西暦の両方で出す。

- 早生まれ（1月1日〜4月1日生まれ。4月1日生まれは前の学年）を自動で判定する
- 改元の年を扱う（2019年3月・4月は平成31年、5月以降は令和元年。1989年1月8日以降は平成元年）
- 浪人年数と、高校・大学・大学院それぞれの在学延長年数（留年・休学・留学）を反映する
- 学歴パターン9種: 中学まで／高校／高専／短大／専門（1〜4年）／大学4年／6年制大学／修士／博士
- 記入日より後は「卒業見込み」「修了見込み」「入学予定」とし、記入日時点の満年齢も出す（2月29日生まれにも対応）
- 学校名を入れてタブ区切りでコピーでき、表計算ソフトや Word の表にそのまま貼れる
- 和暦⇔西暦の変換欄（大正〜令和。改元の年は「昭和64年・平成元年は同じ年」と表示）

企画は10体の仮想エージェント（PM、ユーザー代表3、アーキテクト2、UI/UX 2、セキュリティ2）によるブレストで、ゴミ出しカレンダー・賞味期限管理・割り勘の各案と比べて採択した（`rireki/docs/requirements.md` §0）。市場調査は未実施で、需要は仮説。

## 技術アプローチとアーキテクチャ

- 既存の `mail-check/` と同じく、**1アプリ1フォルダ・依存パッケージ0件・ビルド不要**。`rireki/index.html` を開くだけで動き、既存の Vercel / GitHub Pages の配信にそのまま乗る
- `src/engine.js`: DOM に依存しない純粋関数（UMD）。日付は `{y, m, d}` の整数で扱い、`Date` のタイムゾーンの影響を受けない。元号はデータ表なので、改元時は1行足すだけで済む
- `src/app.js`: DOM 層。描画は `textContent` と `createElement` だけを使う
- セキュリティ: CSP（`default-src 'none'`、`script-src 'self'`、`connect-src 'none'`）、通信 API 不使用、入力内容は保存しない（保存するのは表示テーマだけ）、秘密情報なし。これらは `tests/static.test.mjs` で検査する
- 詳細は `rireki/docs/architecture.md`

## Step 5〜6 のレビューと対応

レビューの内訳: 模擬ユーザー3体、セキュリティ観点2体、**独立レビュー**（別の文脈で動く読み取り専用の code-reviewer）。独立レビューの結論は「日付・学年ロジックと XSS 対策に高重大度の欠陥なし」。指摘は `review-triage` スキルで分類してから修正した（`rireki/feedback/review_report.md` §4）。

修正した指摘:
- 学校名が未入力のとき、仮の名前（○○大学）の行に印を付け、コピー前に警告を出す（R2）
- 生年月日の打ち間違いに気づけるよう、中学卒業前の年齢なら警告を出す。エラーにはしない（R1）
- エラー欄とサマリは文言が変わったときだけ更新する。入力のたびに同じエラーが読み上げられていた。抑止するのは「生年月日の未入力」だけにし、記入日のエラーも出すようにした。エラー時のサマリの誤誘導も直した（R3/R4）
- 学校名から双方向制御文字・ゼロ幅文字・行区切りを除く（R8）
- 和暦→西暦の変換で、改元の年に注記を出す（R5）
- 「保存しません」の文言をテーマの保存と食い違わないように直した（R9）
- `pageshow` で再計算する、コピー後にフォーカスを戻す、エラー欄を `aria-describedby` で関連付ける（R10〜R12）
- 境界値テストを追加: 昭和元年の前日、記入日が3/30・3/31・4/1、博士課程の延長、2/29生まれ、元号の往復（R14）

根拠つきで見送った指摘:
- 数値の丸め（R6）: 入力欄の min/max/step でブラウザが不正値を示す。エンジン側の丸めは異常値への防御として意図したもの
- 表計算の数式インジェクション（R7）: 起きるのは入力者本人の端末内だけ。先頭に `'` を足すと Word への貼り付けで文字が混ざる
- favicon と CSP（R13）: 実ブラウザでコンソールエラー0件。対策のために CSP を緩めない
