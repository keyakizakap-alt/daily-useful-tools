### 出たアイデアと選定

| 案 | 評価 | 結論 |
|---|---|---|
| ゴミ出し分別カレンダー | 自治体ごとのデータ整備が必要で MVP にできない | 見送り |
| 賞味期限トラッカー | 類似アプリが多く差別化しにくい | 見送り |
| 割り勘・端数計算 | 既存の無料アプリが充実 | 見送り |
| **履歴書の学歴年表・和暦早見** | 日本特有（4月入学・早生まれ・和暦・改元）。毎回調べ直す作業で、計算は決定的に正解がある | **採択** |

採択理由（PM まとめ）:
- 課題が日本語圏固有で、正解が1つに決まるため誤りの害（書類の記載ミス）を確実に減らせる。
- サーバー・外部 API・AI が不要で、個人情報を外に出さない設計にできる。
- 市場調査は未実施（このアプリ集は個人の小さな道具の集まりで、収益化は予定しない）。需要は「仮説」。

## 1. 目的

生年月日と最終学歴を入れるだけで、履歴書にそのまま書ける学歴欄（入学・卒業の年月）を
和暦・西暦の両方で出す。早生まれ・浪人・留年・改元の年を自動で正しく扱い、記載ミスを防ぐ。

## 2. 対象ユーザー

- 就職・転職活動中で履歴書・エントリーシートを書く人
- 応募書類を確認する人事・キャリア支援担当
- 役所の書類などで和暦⇔西暦の変換が必要な人

## 3. ユースケース

| ID | ユースケース | 主な流れ |
|---|---|---|
| UC1 | 学歴欄を作る | 生年月日を入力 → 最終学歴を選ぶ → 年表が出る → 「コピー」で貼り付け |
| UC2 | 浪人・留年を反映 | 「詳しい条件」を開き、浪人年数や在学延長年数を入れる → 以降の年がずれる |
| UC3 | 在学中の人が書く | 記入日より後の卒業は「卒業見込み」と表示される |
| UC4 | 学校名も入れて書き写す | 学校名を入れると年表に反映され、コピー結果にも入る |
| UC5 | 年号だけ変換する | 和暦⇔西暦の変換欄で、年（と月日）を入れて変換する |
| UC6 | 満年齢を確かめる | 記入日時点の満年齢が表示される（履歴書の「満○歳」欄） |

## 4. 機能要件

| ID | 要件 | 優先度 |
|---|---|---|
| F1 | 生年月日（西暦）を入力できる。存在しない日付・1926-12-25 より前・記入日より後は日本語のエラーを出す | 必須 |
| F2 | 早生まれ（1月1日〜4月1日生まれ）を判定し、小学校入学年を決める（4月1日生まれは前の学年） | 必須 |
| F3 | 学歴パターン: 中学まで／高校／高専（5年）／短大（2年）／専門学校（1〜4年）／大学（4年）／大学（6年制）／大学院修士／大学院博士（修士2年＋博士3年） | 必須 |
| F4 | 浪人年数（0〜5）と、高校・高校後・大学院の各段階の在学延長年数（0〜5、留年・休学・留学など）を反映する | 必須 |
| F5 | 年月を和暦・西暦の両方で出し、表示を切り替えられる。元年は「元年」と表記する | 必須 |
| F6 | 改元年の境界: 2019年4月は「平成31年」、2019年5月以降は「令和元年」。1989年1月8日以降は「平成元年」 | 必須 |
| F7 | 記入日（初期値は今日）より後の卒業・修了は「卒業見込み」「修了見込み」、入学は「入学予定」とする | 必須 |
| F8 | 記入日時点の満年齢を表示する（誕生日当日に加齢。2月29日生まれは平年は3月1日に加齢） | 必須 |
| F9 | 学校名を任意入力でき、年表とコピー結果に反映する（最大60文字） | 必須 |
| F10 | 年表をタブ区切りテキストでクリップボードにコピーする。小学校の入学・卒業を含めるかを選べる（初期値: 含めない） | 必須 |
| F11 | 和暦⇔西暦の単体変換（大正〜令和）。元号の範囲外の年は日本語のエラーを出す | 必須 |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| N1 | 通信ゼロ。入力内容を送信・保存しない（`localStorage` も使わない。保存するのは表示テーマのみ） |
| N2 | 依存パッケージ0件、ビルド不要。`file://` でも配信でも動く |
| N3 | 全ての UI 文言・エラーメッセージは日本語 |
| N4 | スマートフォン幅（360px）で横スクロールなく使える。キーボードだけで操作できる。ライト／ダーク対応 |
| N5 | CSP で外部への接続・インラインスクリプトを禁止する |
| N6 | 計算ロジックは DOM 非依存の純粋関数とし、`node --test` で境界値をテストする |

## 6. スコープ外（MVP ではやらない）

- 職歴欄の作成、PDF・Word 出力、履歴書全体のテンプレート
- 飛び級・中高一貫の6年表記・通信制などの特殊な学歴（在学延長年数で近似できる範囲のみ）
- 明治以前の和暦、旧暦
- 入力内容の保存・共有
