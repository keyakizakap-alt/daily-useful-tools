# daily-useful-tools

毎日1つ、日本語で使える便利なツール／アプリを自律的に企画・設計・実装していくリポジトリです。毎朝の自動開発ルーティンによって、アイデア出しからMVP実装、フィードバック、改善までを1日単位で完結させます。

## 構成方針

各日のプロダクトは `apps/YYYY-MM-DD-<スラッグ>/` 配下に、以下のサブディレクトリで整理しています。

```
apps/YYYY-MM-DD-<プロダクト名>/
├── design/       設計ドキュメント（コンセプト、UI/画面フロー）
├── requirements/  要件定義書
├── src/           実装コード
├── tests/         テストコード
├── feedback/      レビュー・フィードバックと改善の記録
└── README.md      そのプロダクトの概要・使い方
```
