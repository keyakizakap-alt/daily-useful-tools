# daily-useful-tools

毎日ひとつ、新しいソフトウェアのアイデアを発想し、設計・実装・テスト・フィードバック・改良までを一貫して行うリポジトリです。

各プロジェクトは `projects/YYYY-MM-DD-<プロジェクト名>/` 配下に、日付ごとに独立したフォルダとして格納されます。

## フォルダ構成の規約

各プロジェクトは以下の構成に従います。

```
projects/YYYY-MM-DD-<name>/
├── README.md          # プロジェクト概要・使い方
├── docs/              # 設計ドキュメント
│   ├── idea.md        # アイデア発想の記録（ブレインストーミング結果・選定理由）
│   ├── design.md      # 設計ドキュメント（アーキテクチャ・アルゴリズム・データモデル）
│   └── plan.md        # 実装計画
├── requirements/      # 要件定義
│   └── requirements.md
├── src/               # 実装コード
│   ├── lib/           # 純粋ロジック（ブラウザ・Node の両方から import 可能な ES モジュール）
│   └── web/           # UI（ビルド不要の静的 Web アプリ）
├── tests/             # 自動テスト（node:test）
└── feedback/          # フィードバックと改良の記録
    ├── review.md      # 自己レビュー・模擬ユーザーからのフィードバック
    └── iteration.md   # フィードバックに基づく改良の記録
```

## 設計方針

- **ビルド不要**: バンドラやトランスパイラを使わず、素の ES モジュールで動作させる
- **依存ゼロ**: 外部 npm パッケージに依存しない（テストは Node.js 標準の `node:test`）
- **オフライン完結**: 外部 API・ログイン・サーバを必要とせず、データは端末内に留める
- **ロジックとUIの分離**: 中核ロジックは副作用のない純関数として `src/lib/` に切り出し、単体テスト可能にする
- **日本語UI**: 画面表示・文言はすべて日本語

## テストの実行

各プロジェクトのディレクトリで以下を実行します。

```bash
npm test
# または
node --test tests/*.test.js
```
