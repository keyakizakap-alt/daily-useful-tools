# daily-useful-tools

毎日、新しいソフトウェア/プロダクトのアイデアを考案し、
企画から実装・テスト・フィードバックまでを一気通貫で開発していくリポジトリです。

各アイデアは `ideas/YYYY-MM-DD-<slug>/` ディレクトリにまとめられ、
以下の構成で管理されます。

```
ideas/YYYY-MM-DD-<slug>/
  docs/       アイデア概要・要件定義・設計ドキュメント
  src/        実装（プロトタイプ／MVP）
  tests/      自動テスト
  feedback/   セルフレビュー・改善履歴
  README.md   そのアイデアの概要と使い方
```
