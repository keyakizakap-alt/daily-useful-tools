# 🧰 Daily Useful Tools — 仕事を楽にする道具箱

毎日の仕事でよく使う小さなツールを 1 ページにまとめた、インストール不要の Web アプリです。
依存ライブラリ・ビルド・サーバーは一切不要。`index.html` をブラウザで開くだけで動作します。

## 含まれるツール

| ツール | できること |
| --- | --- |
| ✅ **ToDo** | タスク追加・優先度（重要/通常/あとで）・絞り込み・完了の一括削除 |
| ⏱ **ポモドーロ** | 作業/休憩タイマー、終了時の通知音、当日の完了数カウント |
| 📝 **メモ** | 自動保存されるスクラッチパッド、コピー/クリア |
| 🔤 **テキスト** | 文字数・単語数カウント、大小文字変換、空白整形、行のソート/重複削除/逆順 |
| 🧬 **JSON** | JSON の整形・圧縮・検証（エラー箇所を表示） |

## 特長

- **データはブラウザ内だけに保存** — `localStorage` を使用し、外部送信は一切ありません。
- **ダークモード対応** — OS 設定に追従し、手動切り替えも可能。
- **オフラインで動作** — ネット接続不要。
- **依存ゼロ** — Vanilla JS / HTML / CSS のみ。

## 使い方

1. このリポジトリをクローン、または ZIP でダウンロード。
2. `index.html` をブラウザで開く。

```bash
git clone https://github.com/keyakizakap-alt/daily-useful-tools.git
cd daily-useful-tools
# 任意のブラウザで index.html を開く
```

ローカルサーバーで開きたい場合:

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

```
index.html   画面の構造
styles.css   スタイル（ライト/ダークテーマ）
app.js       各ツールのロジック（依存なし）
```
