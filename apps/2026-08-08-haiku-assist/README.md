# 俳句アシスト（Haiku Assist）

日本語の俳句づくりを支援する、ブラウザだけで動く軽量な静的Webアプリです。
上五・中七・下五を入力すると、促音・拗音・撥音・長音を考慮した正確な音数（モーラ）を
リアルタイムでカウントし、5・7・5の定型に合っているかを色分けで表示します。
あわせて季節ごとの季語辞典から候補を提示し、入力した俳句に季語が含まれているかも自動判定します。

詳しくは `docs/idea.md`（企画）、`docs/requirements.md`（要件定義）、`docs/design.md`（設計）を参照してください。

## 使い方

```sh
cd src
python3 -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

サーバーやビルドツールは不要で、`src/index.html` をブラウザで直接開いても動作します。

## テスト

```sh
node tests/mora.test.js
```

音数カウントのロジック（`src/mora.js`）を、代表的な促音・拗音・撥音・長音を含む
ケースで検証します。

## ディレクトリ構成

```
docs/      企画・要件定義・設計ドキュメント
src/       アプリ本体（HTML/CSS/JS、外部依存なし）
tests/     自動テスト（Node.js標準機能のみで実行可能）
feedback/  セルフレビュー・改善記録
```
