# 実装計画(plan.md)

## 1. 技術選定

- **HTML5 / CSS3 / バニラJavaScript(ES2015+)** のみを使用する。ビルドツール・バンドラ(Webpack, Vite等)・フレームワーク(React, Vue等)は使用しない。
- モジュール分割が必要な場合はブラウザネイティブの `<script type="module">` とESモジュール(`import`/`export`)を用い、ビルドステップなしでそのまま動作させる。
- CSSはプレーンCSS(またはCSSカスタムプロパティによるテーマ変数管理)とし、CSSプリプロセッサ・CDNフレームワークは使用しない。
- データ永続化は `window.localStorage` を使用する。
- 日付・時刻の判定は標準の `Date` オブジェクトのみで行う(外部日付ライブラリは使用しない)。
- グラフ表示(傾向ダッシュボード)は外部チャートライブラリを使わず、CSS/SVGによる簡易な棒グラフ等を自前で実装する。
- フォントはシステムフォント(`-apple-system`, `Hiragino Sans`, `Meiryo` 等のフォントスタック)を使用し、Webフォント配信には依存しない。

## 2. ディレクトリ構成(src/以下、実装時の想定)

```
src/
├── index.html            # エントリーポイント(SPA的に1ファイルで画面切替、または複数HTML)
├── css/
│   ├── base.css           # リセット・共通変数(カラーパレット、テーマ)
│   ├── layout.css         # 縦一列レイアウト・片手操作向けコンポーネント
│   └── components.css     # 封筒・便箋・ボタン等のUIパーツ
├── js/
│   ├── main.js             # 初期化・画面ルーティング
│   ├── storage.js          # localStorage の読み書きラッパー
│   ├── letters.js          # 手紙データのCRUD・配達判定ロジック
│   ├── dashboard.js        # 集計・簡易グラフ描画
│   ├── backup.js           # JSONエクスポート/インポート
│   └── ui/
│       ├── composeForm.js  # 速達フォーム(3ステップ入力)
│       ├── mailbox.js      # 手紙一覧(未配達/配達済み)
│       ├── letterDetail.js # 開封・追記画面
│       └── theme.js        # ライト/ダーク切り替え
└── assets/
    └── icons/               # 封筒・切手等のSVGアイコン(インライン埋め込みも可)
```

※ ビルド不要の方針のため、実装段階で単一HTMLに寄せる/複数ファイルに分けるは実装のしやすさで調整してよいが、外部ビルドツールへの依存は発生させない。

## 3. 画面構成

### 3.1 画面一覧

1. **ホーム(郵便受け)画面**
   - 配達通知バナー(条件を満たした手紙があれば「あなた宛の手紙が届きました」を表示)。
   - 「送らない宣言」バッジを常時表示。
   - 「速達を出す」ボタン(→ 速達フォームへ)。
   - 手紙一覧への導線(未配達・配達済みの件数表示)。

2. **速達フォーム画面(3ステップ)**
   - Step1: 「何があったか」自由記述 + 関係性タグ選択(上司/同僚/家族/友人/パートナー/その他)。
   - Step2: 「本当は何を言いたかったか」自由記述。
   - Step3: 「今の感情」タグ選択(複数選択可。例: 怒り/悲しみ/モヤモヤ/不安/後悔/寂しさ 等)+ 配達日時選択(3日後/1週間後/1か月後/カスタム日付)。
   - 送信(「封をする」)→ 封緘アニメーション → ホームへ戻る。

3. **手紙一覧(郵便箱)画面**
   - 未配達の手紙: 封筒の外観のみ(送信日、関係性タグ)を表示。中身は非表示。
   - 配達済みの手紙: 開封可能な状態で表示され、タップで詳細画面へ。
   - フィルタ(関係性タグ・感情タグ・配達状況)。

4. **手紙詳細/振り返り画面**
   - 配達日を迎えた手紙の本文(出来事・言いたかったこと・当時の感情タグ)を表示。
   - 振り返り追記フォーム: 「今どう思うか」「実際どうなったか」「次にどうしたいか」。
   - 過去の追記ログを時系列(往復書簡形式)で表示。追記は複数回可能。

5. **傾向ダッシュボード画面**
   - 感情タグ別の件数集計(簡易棒グラフ)。
   - 関係性タグ別の件数集計(簡易棒グラフ)。
   - 期間(週/月)ごとの傾向表示。

6. **設定/バックアップ画面**
   - JSONエクスポートボタン(ダウンロード)。
   - JSONインポート(ファイル選択→取り込み)。
   - テーマ切り替え(ライト/ダーク/システムに従う)。
   - 効果音のオン/オフ。

### 3.2 画面遷移(概略)

```
ホーム(郵便受け)
 ├─→ 速達フォーム(Step1→2→3→封緘)─→ ホームへ戻る
 ├─→ 手紙一覧 ─→ 手紙詳細/振り返り(配達済みのみ開封可)
 ├─→ 傾向ダッシュボード
 └─→ 設定/バックアップ
```

## 4. データ構造(localStorage スキーマ案)

localStorageキー例: `kanjo-post:letters`, `kanjo-post:settings`

### 4.1 手紙(Letter)オブジェクト

```json
{
  "id": "letter-uuid-xxxx",
  "createdAt": "2026-08-11T22:30:00+09:00",
  "deliverAt": "2026-08-18T00:00:00+09:00",
  "relation": "boss",
  "emotionTags": ["anger", "moya"],
  "eventText": "会議で理不尽な指摘を受けた出来事の内容",
  "trueFeelingText": "本当はこう言いたかった、という内容",
  "status": "sealed",
  "openedAt": null,
  "reflections": [
    {
      "id": "reflection-uuid-xxxx",
      "createdAt": "2026-08-18T21:00:00+09:00",
      "nowThink": "今どう思うか",
      "whatHappened": "実際どうなったか",
      "nextAction": "次にどうしたいか"
    }
  ]
}
```

- `status`: `"sealed"`(未配達) / `"delivered"`(配達済み・未開封) / `"opened"`(開封済み)
- `relation`: 固定の属性タグID(例: `boss`, `colleague`, `family`, `friend`, `partner`, `other`)
- `emotionTags`: 固定の感情タグID配列(例: `anger`, `sad`, `moya`, `anxiety`, `regret`, `lonely`)
- `reflections`: 追記(振り返り)の配列。1通の手紙に複数追記が積み重なる。

### 4.2 設定(Settings)オブジェクト

```json
{
  "theme": "system",
  "soundEnabled": true
}
```

### 4.3 配達判定ロジック(概要)

- アプリ起動時、および手紙一覧画面表示時に、`status === "sealed"` の全手紙に対して `deliverAt <= 現在日時` を判定する。
- 条件を満たした手紙は `status` を `"delivered"` に更新し、ホーム画面に配達通知バナーを表示する。
- 開封操作(詳細画面を開く)によって `status` を `"opened"` に更新し、`openedAt` を記録する(初回開封のみ記録、以降は再訪可能)。

## 5. エクスポート/インポートJSON形式

```json
{
  "exportedAt": "2026-08-11T22:40:00+09:00",
  "version": 1,
  "settings": { "theme": "system", "soundEnabled": true },
  "letters": [ /* Letterオブジェクトの配列 */ ]
}
```

- インポート時は既存データを上書きするか、マージするかを利用者に選ばせる(最小実装では「上書きのみ」でも可、実装時に判断)。

## 6. 作業ステップ(実装フェーズの想定)

1. **プロジェクト初期化**
   - `src/index.html` の骨組み作成、CSS変数(カラーパレット/テーマ)の定義。
2. **データ層の実装**
   - `storage.js`(localStorage読み書き)、`letters.js`(CRUD・配達判定)の実装。
3. **速達フォーム(Step1〜3)の実装**
   - 入力→一時保存→送信時に `Letter` オブジェクトを生成し保存。封緘アニメーション実装。
4. **ホーム画面・配達通知バナーの実装**
   - 起動時の配達判定ロジックの呼び出しとバナー表示。
5. **手紙一覧・詳細/振り返り画面の実装**
   - 未配達/配達済みの表示切り替え、開封、追記フォームと追記ログ表示。
6. **傾向ダッシュボードの実装**
   - 集計ロジックとCSS/SVGによる簡易グラフ描画。
7. **設定/バックアップ画面の実装**
   - JSONエクスポート/インポート、テーマ切り替え、効果音オン/オフ。
8. **レスポンシブ・片手操作の調整**
   - 縦一列レイアウトの最終調整、タップ領域・フォントサイズの見直し。
9. **ライト/ダークテーマの調整**
   - 低輝度ダークパレットの適用、コントラスト確認。
10. **動作確認・簡易テスト**
    - `tests/` にlocalStorageロジック・配達判定ロジック等の手動/簡易テストを配置し、主要ユースケースを一通り確認する。
