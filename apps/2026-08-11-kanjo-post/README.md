# 感情の郵便局

## これは何か

「感情の郵便局」は、人と気まずいやり取りをした直後のモヤモヤを、その場でスマホに書き出して「手紙」として封をし、あえて数日〜数週間後まで開封できない状態にして未来の自分に配達する、一人暮らし社会人向けの一人内省ツールです。

対象は、日中の対人関係(上司・同僚・家族・友人など)でのすれ違いや理不尽な出来事を抱え込みやすい、一人暮らしの社会人です。誰かに送ることも、誰かに見せることもありません。この手紙の宛先は、常に「未来の自分」です。

## なぜ既存のアプリでは足りないのか

- **日記アプリ**は「書いて終わり」です。書いた瞬間に気持ちが整理されることはあっても、後日読み返して自分の変化に気づく仕組みは弱く、書きっぱなしになりがちです。
- **チャット型相談アプリ・AI相談サービス**は「即時に答えをもらう」ことを目的としています。すぐに助言や慰めが返ってくる安心感はありますが、モヤモヤの反芻(何度も同じ怒り・後悔を頭の中で再生してしまうこと)を止める効果は限定的です。

「感情の郵便局」はこれらとは異なり、**「時間差」そのものを核に据えた設計**をとります。書いた内容をすぐには読み返せないようにし、あえて配達を数日〜数週間先に設定することで、次の三段構えの内省体験を提供します。

1. **即座の反芻思考を止める心理的距離をつくる**
   出来事を書き出して「封をする」という行為そのものが、頭の中でループしている感情に区切りをつけ、「もう考えなくていい状態」を物理的・視覚的に作り出します。

2. **時間経過後の自分という第三者視点で同じ出来事を読み返せる**
   数日〜数週間後、感情の熱が冷めた状態で当時の自分の言葉に向き合うことで、感情に飲まれていたときには見えなかった気づきや、意外な冷静さを得られます。

3. **一通の手紙に追記が積み重なり、対人関係の"経過"が自然に記録される**
   同じ相手・同じ出来事について、受け取った後の気持ちや実際の顚末を追記していくことで、往復書簡のように関係性の変化が時系列で残っていきます。

## 大切にしていること

- **誰にも送らない・誰にも見せない**ことを明言します。このアプリには相手に送信する機能が一切ありません。書く内容は完全に自分だけのものです。
- **郵便局という温かみのあるメタファー**を採用し、SNSやメッセージアプリのような即時性・他者評価のプレッシャーとは一線を画す、静かで安心できる体験を目指します。
- 相手の実名など個人が特定される情報は書き込ませず、「上司」「家族」「友人」といった関係性タグのみで記録することで、心理的安全性を担保します。

## 主なユースケース

- 上司に理不尽なことを言われてモヤモヤしたまま帰宅した夜、出来事と本当に言いたかったことを書き出して封をし、頭の中から一旦追い出して眠る。
- 家族と気まずい電話をした後、配達日を1週間後に設定した手紙を送り、時間が経ってから冷静な気持ちで読み返し、実際に連絡するかどうかを判断する。
- 友人に言いそびれた本音を書き留めておき、1か月後に届いた手紙を読み返して「やっぱり伝えるべきだった」「もう気にならなくなった」と自分の変化を確認する。
- 月末に傾向ダッシュボードを見返し、「特定の会議の後にいつもイライラが溜まっている」といった自分のパターンに気づき、次回への対策(会議前にひと呼吸置く等)を立てる。
- 同じ相手との気まずさが繰り返し起きたとき、過去の手紙に追記を重ねていくことで、関係の経過や自分の対応の変化を時系列で振り返る。

## MVPのコア機能

- **速達フォーム**: 「何があったか」「本当は何を言いたかったか」「今の感情(タグ選択)」を3ステップで入力し、送信すると画面上から内容が見えなくなる封緘演出。
- **配達日時の指定**: 3日後・1週間後・1か月後・カスタム日付から選択し、指定日までは封筒の外観(送信日・関係性タグのみ)しか表示されない一覧管理。
- **配達通知バナー**: アプリを開いた際に現在日時と配達予定日を照合し、条件を満たした手紙を「あなた宛の手紙が届きました」として自動的に開封可能状態にする。
- **受け取り時の振り返りテンプレート**: 「今どう思うか」「実際どうなったか」「次にどうしたいか」を追記でき、同じ手紙に複数回の追記が積み重なる往復書簡形式のログ。
- **送らない宣言UI**: 相手に直接送信する機能を持たないことを常時表示し、実名ではなく関係性タグ(上司/家族/友人など)のみを記録させる安心設計。
- **傾向ダッシュボード**: 蓄積した手紙を感情タグ・相手属性で集計し、気まずくなりやすい場面のパターンを簡易グラフで可視化。
- **ローカル完結のデータ管理**: 全データをlocalStorageに保存し、JSON形式でのエクスポート/インポートによるバックアップ・端末移行機能を提供。

## 使い方

ビルドや依存パッケージは不要です。`src/index.html` をブラウザで直接開くだけで動作します。
