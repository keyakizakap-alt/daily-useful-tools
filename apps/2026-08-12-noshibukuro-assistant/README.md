# のし袋アシスタント（2026-08-12）

冠婚葬祭でのし袋（祝儀袋・不祝儀袋）を用意する際に迷いがちな「表書き」「水引の種類」「金額の相場」「金額の大字（漢数字）表記」を、行事と関係性を選ぶだけでまとめて確認できる日本語Webアプリです。

外部API・アカウント登録・ビルドツール不要。`src/index.html` をブラウザで直接開くだけで動作します。

## フォルダ構成

```
2026-08-12-noshibukuro-assistant/
├── design/          設計ドキュメント（コンセプト・UI/画面フロー）
├── requirements/     要件定義書（機能要件・非機能要件・受け入れ基準）
├── src/              実装（静的HTML/CSS/JS、データ）
│   ├── index.html
│   ├── style.css
│   ├── app.js         画面制御（DOM操作）
│   ├── logic.js        コアロジック（大字変換・データ検索、UMD形式）
│   └── data/
│       └── occasions.data.js  行事・相場データ（UMD形式）
├── tests/            テスト
│   └── test-logic.js  ロジック層のユニットテスト（Node.jsで実行）
└── feedback/         フィードバックと改善の記録
    ├── round1-review.md
    └── iteration-notes.md
```

## 使い方

ブラウザで `src/index.html` を開くだけです。サーバーは不要です。

## テストの実行

```bash
node tests/test-logic.js
```

ロジック層（大字変換・相場レンジ判定・データ検索）を検証する19件のユニットテストが実行されます。UI自体はPlaywright（headless Chromium）による手動検証で確認済みです（`feedback/` 配下に記録）。

結婚祝い／出産祝い／香典（仏式・通夜葬儀）／香典（仏式・四十九日以降）／香典（神式）／香典（キリスト教式）／入学・卒業祝い／就職祝い／快気祝い／お年玉／新築祝い

## 免責事項

表書き・水引・金額相場は一般的な目安です。地域やご家庭、宗派によって慣習が異なる場合がありますので、実際に用意する際は年長者や地域の慣習に詳しい方にご確認ください。
