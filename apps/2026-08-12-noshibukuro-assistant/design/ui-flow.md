# UI / 画面フロー設計

## 画面構成（単一ページ、上から下へのステップ形式）

1. **ヘッダー**: アプリ名「のし袋アシスタント」＋一言説明
2. **ステップ1: 行事を選ぶ**
   - セレクトボックス（例: 結婚祝い／出産祝い／香典（仏式）／御霊前・御仏前／入学・卒業祝い／快気祝い／お年玉 等）
3. **ステップ2: 関係性を選ぶ**
   - セレクトボックス（例: 親・祖父母／兄弟姉妹／親戚／友人・知人／会社の同僚／会社の上司・取引先／近所の人）
   - 行事によっては非表示（例: お年玉は「子どもの年齢」に差し替え）
4. **ステップ3: 金額を入力（任意）**
   - 数値入力欄。相場レンジ内かどうかの簡易フィードバックを表示
   - 入力すると自動的に大字（漢数字）表記に変換して表示
5. **結果カード（自動更新）**
   - 表書き候補（複数ある場合は使い分けの注釈）
   - 水引の種類・色・結び方（説明文＋簡易アイコン）
   - 金額相場（関係性別レンジ）
   - 大字変換結果（例: 「金参萬円」）
   - 名前の書き方の注意点（連名の順序など）
6. **フッター**: 免責事項（地域や宗派で慣習が異なる場合がある旨）

## インタラクション方針

- 選択が変わるたびに結果カードをリアルタイム更新（送信ボタンなし）
- スマートフォンでの片手操作を想定し、セレクトボックスは大きめ、結果は縦スクロールで完結
- 金額入力は任意項目とし、未入力でも表書き・水引の情報は表示される

## 状態管理

- フレームワーク不使用。Vanilla JS でDOM操作。
- アプリの状態（選択中の行事・関係性・金額）はJSのオブジェクトで保持し、`render()` 関数で結果カードを再描画。
- ロジック（大字変換・データ検索）は `logic.js` に分離し、UI（`app.js`）から呼び出す。`logic.js` はブラウザとNode.js（テスト用）の両方から読み込めるUMD風の形にする。
