# のし袋アシスタント — コンセプト設計書

作成日: 2026-08-12
担当: Daily Useful Tools 自動開発ルーティン

## 1. 背景・課題

冠婚葬祭でのし袋（祝儀袋・不祝儀袋）を用意する際、多くの日本人が以下の点で毎回迷う。

- 表書き（「御祝」「寿」「御仏前」「御霊前」など）はどれが正しいのか
- 水引の種類・結び方（蝶結び／結び切り／あわじ結び）と色は行事によって異なる
- 金額の相場は関係性（親族・友人・会社関係など）によって変わる
- 金額を漢数字の「大字（だいじ）」表記（例: 30,000円 → 金参萬円）にどう変換すればよいか

これらはマナー本やWeb記事を都度検索すれば分かるが、情報が散在しており、行事ごとに複数ページを見比べる必要がある。また金額の大字変換は手計算が面倒で誤記しやすい（改ざん防止のための重要な作法であるにもかかわらず）。

## 2. 解決の方向性

行事の種類と関係性を選ぶだけで、以下を1画面でまとめて提示するワンストップ型の診断ツールを作る。

1. 正しい表書き（複数候補がある場合は使い分けの注釈付き）
2. 水引の種類・色・結び方
3. 金額相場の目安（関係性別）
4. 入力した金額を大字（漢数字）表記に自動変換
5. 名前の書き方（連名時の順序など）の簡単な注意点

## 3. 差別化ポイント

- 既存のマナーサイトは「読み物」中心で、選択→即答のツール型UIではない。
- 金額の大字変換を単体で提供するツールは存在するが、表書き・水引・相場の診断と統合されているものは少ない。
- アカウント登録・サーバー通信が一切不要（静的HTML/CSS/JSのみ、データはすべてローカルの静的JSON）。オフラインでも動作する。
- スマートフォンでの利用を想定し、冠婚葬祭の直前（コンビニでのし袋を買った後など）にサッと確認できるUIにする。

## 4. 対象ユーザーとユースケース

- 結婚式に招待され、祝儀袋を書く前に金額と表書きを確認したい会社員
- 通夜・葬儀に参列する前に「御霊前」か「御仏前」か迷っている人
- 出産祝い・入学祝いなど、頻度は低いが失敗できない場面でマナーを確認したい人
- 幹事や会社の代表として連名で贈る際の名前の並べ方を確認したい人

## 5. スコープ外（今回のMVPでは扱わない）

- 実際ののし袋のデザイン印刷・PDF出力（将来拡張の候補）
- 地域差（関東・関西で水引の色慣習が異なる等）の完全網羅（代表的な注記のみ記載し、断定を避ける）
- 宗教・宗派ごとの詳細な違い（仏式・神式・キリスト教式の代表パターンのみ対応）
