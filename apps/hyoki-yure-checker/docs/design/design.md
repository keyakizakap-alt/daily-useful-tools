# 設計ドキュメント: 表記ゆれ統一チェッカー

## アーキテクチャ方針

- 完全にクライアントサイドで完結する静的Webアプリ(HTML/CSS/Vanilla JS、
  ビルドツール・フレームワーク不使用)。
- 検出・置換ロジックは `src/lib/detector.js` にES Modulesの純粋関数として
  実装し、DOM操作(`src/app.js`)から分離する。これにより Node.js の
  テストランナーからロジックを直接importしてユニットテストできる。
- 依存パッケージなし。CDNからの外部ライブラリ読み込みも行わない
  (完全オフラインで動作可能)。

```
src/
  index.html   … 画面構造
  style.css    … スタイル
  app.js       … DOMイベント処理、detector.jsの呼び出し、描画
  lib/
    detector.js … 表記ゆれ検出・置換の純粋関数群(テスト対象)
```

## 検出アルゴリズム

### 1. 全角/半角英数字の表記ゆれ

1. 正規表現 `/[0-9A-Za-z0-9０-９Ａ-Ｚａ-ｚ]+/g` で英数字の連続部分(トークン)
   をすべて抽出する。
2. 各トークンを「半角正規化」する。全角英数字は Unicode コードポイントで
   `0xFEE0` を引くと対応する半角文字になる性質を利用する
   (`fullwidthToHalfwidth`関数)。
3. 正規化後の値をキーとして出現トークン(表記そのまま)をグルーピングする。
4. 同一キーに対し、出現した「表記そのまま」の異なり数が2以上であれば
   表記ゆれとして検出する。

### 2. 長音符号「ー」有無によるカタカナ表記ゆれ

1. 正規表現 `/[ァ-ヶー]{2,}/g` でカタカナ(長音符号含む)の連続部分を
   2文字以上のトークンとして抽出する。
2. 各トークンから「ー」をすべて除去した文字列をキーとする。
3. 同一キーに対し、出現した「表記そのまま」の異なり数が2以上であれば
   表記ゆれとして検出する。
   - 例: 「サーバ」→キー`サバ`、「サーバー」→キー`サバ`。同一キーに
     2つの表記が存在するため検出される。
   - 「ー」が全く含まれない単語同士(例:「テスト」だけ)しか出現しない
     場合はグループの異なり数が1なので検出されない。

### 3. 統一(置換)処理

- `applyUnification(text, replacements)` は `{ from, to }` の配列を受け取り、
  各 `from` の出現をすべて `to` に置換した新しいテキストを返す。
- 置換は「出現回数の多い表記」をデフォルトの統一先とするが、UIから
  ユーザーが逆方向を選ぶこともできる。
- 置換順序による誤爆(例: 短い文字列が長い文字列の一部として誤って
  置換される)を避けるため、置換対象文字列は長い順にソートしてから
  適用する。

## データモデル (JS上の型のイメージ)

```js
// Finding: 1つの表記ゆれグループ
{
  type: "width" | "chōon",   // 検出種別
  key: string,                // 正規化後のグルーピングキー
  variants: [
    { surface: string, count: number }
    // countの降順でソート
  ]
}
```

## UI設計

1. **入力エリア**: 大きめのテキストエリア + 「チェックする」ボタン
2. **結果一覧**: Findingごとにカードを表示
   - 種別バッジ(「全角/半角」「長音」)
   - バリエーションと出現回数の一覧(ラジオボタンでどちらを残すか選択、
     初期値は出現回数が多い方)
   - 「このグループを統一する」ボタン
3. **全体操作**: 「すべて一括で統一する」ボタン、「結果をコピー」ボタン
4. **プレビュー**: 検出箇所を `<mark>` でハイライトした読み取り専用の
   プレビュー(統一実行のたびに再描画)
5. **プライバシー表示**: 「入力したテキストは外部に送信されず、
   ブラウザ内のみで処理されます」という注記を画面上部に常時表示
6. 表記ゆれが0件の場合は「表記ゆれは見つかりませんでした 🎉」を表示

## エラー・エッジケースの扱い

- 空文字列でチェックした場合: 「テキストを入力してください」と案内
- 1文字のトークンは英数字・カタカナともに検出対象外(誤検出が多いため)
- 大文字小文字は区別する(「Server」と「SERVER」は表記ゆれ対象外。
  スコープは全角半角と長音のみのため)
