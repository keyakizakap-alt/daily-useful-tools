# ブレインストーミング: 生産性・仕事効率化領域

エージェント: general-purpose (並行ブレインストーミング担当 1/6)
条件: ブラウザだけで動く単機能Webアプリ(バックエンド不要)。16案。

- **会議コストビジュアライザー**: 参加人数と平均時給から会議中の人件費をリアルタイム表示
- **発言時間トラッカー**: 会議参加者ごとの発言時間を計測し比率を円グラフ表示
- **原稿用紙換算カウンター**: 文字数・単語数に加え400字詰め原稿用紙換算枚数を計算
- **表記ゆれ統一チェッカー**: 全角/半角・カタカナ表記ゆれをハイライトし一括統一 ← **採用**
- **テキスト差分チェッカー**: 2つのテキストの追加・削除・変更箇所を色分け表示
- **作業タブ復元ツール**: 開いているタブをセットとして保存・復元
- **Markdownスライドプレビューア**: Markdown箇条書きをスライド風に表示
- **工数見積り人日計算機**: タスク一覧から合計工数・見積金額を自動集計
- **定型文フレーズ帳**: よく使うビジネス文をカテゴリ別に登録・検索
- **スクリーンショット注釈ツール**: 画像に矢印・モザイク・テキストを書き込み保存
- **QRコード即時ジェネレーター**: URLやWi-Fi情報をブラウザ内のみでQR化
- **ポモドーロ作業ログタイマー**: セッションごとの作業メモを記録・日別集計
- **締め切りカウントダウンボード**: 複数案件の締め切りを緊急度順にカード表示
- **CSVマージ・比較ツール**: 2つのCSVをキーでマージ・差分抽出
- **読み上げTODOリスト**: TODOを音声読み上げし完了で自動的に次を読み上げ
- **日報・週報自動整形ツール**: 箇条書きメモを定型フォーマットの日報に整形

(全16案の詳細な一言・対象ユーザー・ユースケース・新規性は選定時のセッションログを参照)
