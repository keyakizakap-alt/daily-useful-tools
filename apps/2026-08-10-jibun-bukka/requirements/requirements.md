# 要件定義書 — じぶん物価

## 1. 背景・目的

公式の消費者物価指数（CPI）は品目バスケットが世帯ごとの実感と乖離しやすい。本アプリは、ユーザーが実際に買っている品目の価格だけを記録し続けることで、「自分だけの体感インフレ率（じぶん物価指数）」を算出し、値上げの実感を可視化することを目的とする。

## 2. 対象ユーザー

- 日々の買い物（食料品・日用品・光熱費など）の値上がりを実感し、記録・把握したい個人ユーザー
- 家計簿アプリの「総額管理」ではなく「品目単価の推移」に関心があるユーザー

## 3. スコープ

- 完全クライアントサイド動作の単一ページWebアプリ（HTML/CSS/JavaScript）
- 外部API・サーバー・データベース通信は一切行わない
- データはブラウザの `localStorage` にのみ保存する
- UIはすべて日本語

## 4. 機能要件

| ID | 要件 |
|----|------|
| F1 | 品目名・価格・購入日を入力して価格記録を追加できること |
| F2 | 品目名入力時、過去に入力済みの品目名からオートコンプリート候補を表示すること |
| F3 | 同一品目名の記録は自動的に時系列でグルーピングされ、一覧・グラフで参照できること |
| F4 | 品目ごとの価格推移を折れ線グラフ（SVG）で表示できること |
| F5 | 品目ごとに「初回価格からの変化率（%）」を表示すること |
| F6 | 全品目の変化率から「じぶん物価指数（%）」を自動算出し、トップに表示すること |
| F7 | 値上がり率が大きい品目トップ5を「値上がりランキング」として表示すること |
| F8 | 記録の一覧表示・個別削除ができること |
| F9 | 全データをCSV形式でエクスポートできること |
| F10 | CSVファイルをインポートしてデータを復元・追加できること |
| F11 | 記録が0件、または1件のみの品目は指数計算・ランキングから除外し、その旨をUIでわかりやすく示すこと |

## 5. 非機能要件

| ID | 要件 |
|----|------|
| N1 | 外部ネットワーク通信を行わない（フォント・CSS・JS・画像もすべてローカルに同梱） |
| N2 | スマートフォン幅（375px程度）からデスクトップ幅まで、レスポンシブに表示できること |
| N3 | ページ再読み込み後もlocalStorageからデータを復元できること |
| N4 | 主要ロジック（指数計算・ランキング・CSV変換）は純粋関数として実装し、Node.jsの標準テストランナーで単体テスト可能な形にすること |
| N5 | 依存ライブラリを追加しない（フレームワーク・npmパッケージ不使用） |

## 6. じぶん物価指数の算出方法

1. 記録が2件以上ある品目のみを対象とする
2. 各品目について `変化率(%) = (最新価格 - 最初の価格) / 最初の価格 * 100` を算出する
3. 対象品目全体の変化率の単純平均を「じぶん物価指数」とする
4. 対象品目が0件の場合は指数を算出せず、データ不足である旨を表示する

## 7. 受け入れ基準

- ブラウザで `src/index.html` を直接開くだけで動作すること（ビルド不要）
- 品目を2回以上記録すると、じぶん物価指数とランキングが表示されること
- ページを再読み込みしてもデータが保持されること
- CSVエクスポートしたファイルを再インポートすると同じデータが復元されること
- `npm`不要で `node --test` によりロジックの単体テストが実行できること
