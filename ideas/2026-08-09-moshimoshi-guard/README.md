# もしもしガード

電話がかかってきている「その場」で使う、特殊詐欺（オレオレ詐欺・還付金詐欺・架空請求詐欺など）の危険度チェックツールです。

相手が言った内容に近いフレーズのボタンを押していくだけで、危険度スコアと「今すぐ電話を切る」などの次の行動が、大きな文字で画面に表示されます。

インターネット通信・サーバー・ビルド環境は一切使用しません。HTML/CSS/JavaScriptのみで動作する静的ページで、入力した情報はすべてお使いの端末内の `localStorage` に保存されます（外部には一切送信されません）。

## こんな時に使います

- 固定電話や携帯電話（スピーカーフォンなど）で話をしながら、もう片方の手でスマートフォン・タブレット・パソコンでこのツールを操作します。
- 電話の相手が言った内容に近いボタンを押すたびに、危険度スコアがその場で上がっていきます。
- 危険度が「高」になると、画面が赤くなり、「今すぐ電話を切ってください」というメッセージと、家族の緊急連絡先ボタンが大きく表示されます。

離れて暮らすご家族がいる場合は、あらかじめこのページをシニアの端末にブックマークしておき、「設定」画面から緊急連絡先を登録しておくことをおすすめします。

## 使い方

### 1. ページを開く

`src/index.html` をブラウザで開くだけで使えます（インストール不要）。

ローカルファイルとして直接開いても、簡易HTTPサーバーで配信しても、どちらでも動作します。簡易サーバーで確認する場合の例:

```bash
cd ideas/2026-08-09-moshimoshi-guard/src
python3 -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

### 2. 緊急連絡先を登録する（最初に一度）

ホーム画面の「⚙️ 緊急連絡先の設定」から、家族などの名前・続柄・電話番号を登録します。少なくとも1件を「最優先の連絡先」に指定しておくと、危険度が「高」になったときに一番目立つ位置に表示されます。

### 3. 電話がかかってきたらチェックを始める

ホーム画面の「📞 電話中チェックを始める」を押します。

相手が言った内容に近いフレーズのボタンをタップしていくと、画面上部のバナーに危険度スコアと判定レベル（低・中・高）がリアルタイムで表示されます。判定レベルに応じて、次に取るべき行動が大きな文字で表示されます。

- **低（安全）**: 引き続き注意しながら会話を続けましょう。
- **中（注意）**: 一度電話を切って、ご家族に確認しましょう。
- **高（危険）**: 今すぐ電話を切ってください。折り返さず、緊急連絡先へ連絡しましょう。

「ATMに行くよう指示された」「キャッシュカードを渡すよう言われた」など、特に危険なフレーズは1つ選んだだけでも自動的に「高（危険）」判定になります。

必要に応じて、相手が名乗った名前・電話番号・要求内容・その他メモを入力できます。入力内容は自動的に保存されるため、途中で画面を閉じたり誤ってリロードしても内容は消えません。

チェックが終わったら、「✅ チェックを終了して保存」を押すと履歴に記録されます。記録を残したくない場合は「保存せず終了する」を選べます。

### 4. 履歴を見る・印刷する

ホーム画面の「📋 チェック履歴を見る」から、過去のチェック結果を新しい順に確認できます。各履歴の「詳細を見る」で、選択したフレーズやメモの全文を確認できます。

「🖨 印刷する」ボタンで、家族や警察へ説明する際に紙で持ち出せる記録として印刷できます。不要な履歴は「削除」ボタンから個別に削除できます（削除前に確認ダイアログが表示されます）。

### 5. 文字の大きさを変える

画面右上の「A-」「A+」ボタンで、全体の文字サイズを小さく・大きくできます。

## データの保存について（プライバシー）

- 入力したすべての情報（通話メモ・緊急連絡先・チェック履歴）は、お使いの端末の `localStorage` にのみ保存されます。
- サーバーへの送信、外部サイトとの通信、アクセス解析、クッキーなどは一切使用していません。
- ブラウザの「閲覧データを削除」などの操作を行うと、保存した情報も消去されますのでご注意ください。

## 開発者向け情報

### 技術方針

- 依存パッケージ・ビルドステップなし。`src/core.js` はNode.jsから `require()` で、ブラウザからは `<script src="core.js"></script>` でそのまま読み込めるUMD風の形式で実装しています。
- `core.js` はDOM・`localStorage` に依存しない純粋関数を中心に構成し、`localStorage` を扱う関数は「ストレージ実装（`getItem`/`setItem`を持つオブジェクト）」を引数として注入できる設計にしています。これによりNode.js環境でも `localStorage` なしでテストできます。
- `app.js` はDOM操作・画面遷移・イベント処理のみを担当し、判定ロジックは持ちません。

### テストの実行方法

追加のパッケージインストールは不要です。Node.js標準の `node:test` を使用します。

```bash
node --test ideas/2026-08-09-moshimoshi-guard/tests/core.test.js
```

すべてのテストがパスすることを確認してください。

## スコープ外（今後の課題）

- 通話の音声認識による自動フレーズ検出（本ツールは手動でのボタン選択のみに対応）
- 電話番号のブラックリスト照会など、外部データベース・APIとの通信
- 家族へのプッシュ通知・SMS・メールなどの自動送信
- 複数端末間でのデータ同期・クラウドバックアップ
- 日本語以外の多言語対応

詳細な要件・設計は `docs/requirements.md` と `docs/design.md` を参照してください。
