# 要件定義: スマート割り勘 (Smart Warikan)

## 1. 機能要件

### 1.1 メンバー管理
- FR-1: ユーザーはグループの参加者（名前）を追加・削除できる。
- FR-2: 参加者は2名以上登録できる（1名では割り勘が成立しないため）。

### 1.2 支出の記録
- FR-3: ユーザーは支出を登録できる。各支出は以下を持つ。
  - 品目名（任意入力、未入力時は「支出」等のデフォルト表記）
  - 金額（円、正の整数）
  - 支払者（参加者から1名選択）
  - 割り勘対象者（参加者から複数選択。デフォルトは全員）
  - 割り勘方法：均等割り／人数を保ったまま金額比で指定（例: Aは2人分）
- FR-4: 登録済みの支出は一覧表示・削除できる。

### 1.3 精算計算
- FR-5: 全支出から各参加者の純収支（払った額 − 負担すべき額）を計算する。
- FR-6: 純収支をもとに、貸し借りをゼロにするために必要な送金の
  組み合わせを、送金回数が最小になるように計算する。
  - 端数（1円未満は発生しないが、割り切れない場合の端数円）は
    合計金額を守った上でいずれかの参加者に寄せる。
- FR-7: 精算プランは「Aさん → Bさんへ ¥XXX」の形式で一覧表示する。
- FR-8: 貸し借りがすでにゼロの参加者、および送金額が0円になる
  組み合わせは結果に表示しない。

### 1.4 出力・共有
- FR-9: 精算結果をテキスト形式でクリップボードにコピーできる。

### 1.5 日本語対応
- FR-10: UI文言はすべて日本語。金額は日本円（¥）表記、
  3桁区切りカンマを用いる。

## 2. 非機能要件

- NFR-1: サーバー・データベース不要。静的ファイル（HTML/CSS/JS）のみで
  ブラウザ上に完結する。
- NFR-2: 入力データは外部に送信しない（プライバシー配慮）。
- NFR-3: スマートフォンの縦画面でも操作可能なレスポンシブレイアウト。
- NFR-4: 精算計算のコアロジックは純粋関数として実装し、
  自動テストで検証可能にする。
- NFR-5: 主要ブラウザ（Chrome, Safari, Firefox 最新版）で動作する。

## 3. スコープ外（今回のMVPでは対応しない）

- 複数グループ・複数通貨対応
- ユーザー認証・データの永続保存（サーバー保存）
- 履歴の月次集計・グラフ表示
- 多言語対応（日本語のみ）
