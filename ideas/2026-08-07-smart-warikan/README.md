# スマート割り勘 (Smart Warikan)

2026-08-07 のアイデア。グループの支出を記録すると、
**送金回数が最少になる精算プラン**を自動計算する、
サーバー不要・日本語UIのWebアプリです。

## 使い方

ブラウザ（`file://` でも可）で `src/index.html` を開くだけで動作します。
ローカルサーバー経由で確認する場合は次のように起動してください。

```sh
cd src
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## テストの実行

コアの精算アルゴリズムは Node.js 標準の `node:test` でテストしています
（追加の依存パッケージは不要）。

```sh
npm test
# または: node --test
```

## 主な機能

- 参加者の登録・削除
- 支出の登録（品目・金額・支払者・割り勘対象者・負担割合を指定可能）
- 「貸し借りをゼロにする送金回数が最小になるプラン」を自動計算
- 結果をワンクリックでテキストコピー（`file://` でも動作するフォールバック付き）
- データは外部送信されず、ブラウザ内のみで完結

## 動作確認

- `node --test` でユニットテスト9件が全て成功することを確認済み
- Playwright + Chromium による実ブラウザでのE2Eスモークテストで、
  均等割り・重み付き分割・結果コピーの一連の操作が正しく動作することを確認済み
